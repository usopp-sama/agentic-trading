Liquid Glass wallpapers
=======================

Drop your own images here — .jpg / .jpeg / .png / .webp / .avif / .gif / .svg.

The Liquid Glass theme (palette button → Theme → Liquid Glass) picks one at
random on load and cross-fades to another every 45 seconds. Anything you add
shows up automatically via /api/wallpapers — no restart, no manifest to edit.

The five 0X-*.svg files shipped here are lightweight vector gradient defaults so
the theme looks good out of the box. Add your own "OG" wallpapers alongside (or
delete the defaults) and they join the rotation.

Tips:
- Landscape images ~1600×1000 or larger look best (they're cover-fit + centered).
- A legibility scrim + the frosted panels sit on top, so busy photos still work,
  but calmer/darker images keep text crispest.
- Set Motion → Calm (palette button) to stop the rotation and hold one image.
