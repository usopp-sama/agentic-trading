# Vendored fonts (OFL)

Served locally (no runtime CDN) for the Minecraft theme.

| File | Font | License | Source |
|------|------|---------|--------|
| `press-start-2p.woff2` | Press Start 2P | SIL Open Font License 1.1 | fontsource (`press-start-2p`) |
| `vt323.woff2` | VT323 | SIL Open Font License 1.1 | fontsource (`vt323`) |

These are open-licensed pixel fonts used for the original (non-Mojang) blocky
look. The Minecraft *theme* uses original CSS styling, not Mojang assets.
